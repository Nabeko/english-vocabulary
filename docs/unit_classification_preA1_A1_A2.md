# pre-A1/A1/A2 跨等級主題分類 v1.0（取代 unit_classification_preA1_draft.md）

來源：YLE Starters/Movers/Flyers A–Z Word List（官方PDF，pdftotext純文字解析 + 程式比對KET Appendix2主題字庫 + 人工補分類）

分類依據：13個統一Unit（見 docs/unit_topics_mapping.md）。原10-unit草稿（unit_classification_preA1_draft.md）已過時，以此文件為準。

> 說明：人名（Alex/Ben/Lucy等專有名詞）、驚嘆語/招呼語（bye!/hello!等）、純功能詞（冠詞/介詞/代名詞/疑問詞）、
> 通用動詞（get/go/make/have/do等不具主題性的動詞）、通用形容詞（new/sad/long/short等）、
> 通用副詞（now/here/very/really等）均歸入「High-Frequency / Core Words」，不勉強塞進主題分類。

> 新增「Animals & Pets」為第13個Unit：KET官方Appendix 2的22個主題中完全沒有「動物」分類，
> 但YLE三級含大量動物單字，經使用者2026-11-14確認獨立成Unit（詳見 unit_topics_mapping.md）。

> 此為程式輔助分類草稿，部分邊界字（如一字多義：file/match/bit等）可能需要你抽查微調，
> 詳細抽查建議已記錄在 memo.md 待辦事項。
